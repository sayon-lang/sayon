# Sayon's logo

The logo is an S made of two rounded pieces that fit into each other. Its color is vermilion, `#DB5735`.

| File | Use it for |
| --- | --- |
| `logo.svg` | Pages and documents, at any size |
| `logo-animated.svg` | The top of the README: the two pieces slide together, then the S makes a half turn every eight seconds, and stays still for anyone who asks their system for less motion |
| `logo-black.svg` (`#1F1A17`), `logo-white.svg` | Places without color, and dark photographs |
| `logo.png`, `icon-512.png`, `icon-128.png` | Places that only take images: 1024, 512, and 128 pixels |
| `sayon.ico` | The Windows icon for `sayon.exe`, the installer, and `.sayon` files, from 16 to 256 pixels |

The VS Code extension uses the 128 and 32 pixel images.

Each image sits on a square canvas with a transparent margin. Keep it square, and please don't crop, stretch, or recolor it, or add gradients or shadows.
